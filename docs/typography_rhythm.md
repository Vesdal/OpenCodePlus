# Typography and Rhythm

## 1. Roles
Define a compact type ramp:
- display (rare);
- title;
- section title;
- body;
- secondary/body-small;
- label;
- caption;
- numeric/data styles if required.

## 2. Do not use display type everywhere
Large headings attract attention and consume space.
Use them only when hierarchy demands it.

## 3. Line height
Line height should be chosen for reading rhythm, not by copying a random percentage.
Dense controls may use tighter line height than prose.

## 4. Weight
Use a limited weight family:
- regular;
- medium;
- semibold/bold only when useful.

Too many weights weaken hierarchy.

## 5. System vs bundled fonts
Use platform system fonts where platform-native fidelity or accessibility benefits.
Bundle a font when:
- redistribution is licensed;
- the design requires cross-platform identity;
- the font is available in the required weights/styles.

Never bundle Apple's proprietary system fonts into a Windows app without explicit licensing permission.

## 6. Baseline rhythm
Align text to a shared baseline whenever practical.
Avoid visually centering text in ways that fight the typographic baseline.

## 7. Numbers
For tables, metrics, times, and financial values, use tabular/lining numerals where appropriate.

## 8. Language
Use sentence case by default unless the chosen platform/product language intentionally uses another pattern.
