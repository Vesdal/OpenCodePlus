# Agent Knowledge Workflow

Canonical acquisition procedure: [Knowledge Acquisition and Retrieval](knowledge/research_workflow.md).

Start with [the knowledge index](knowledge/KNOWLEDGE_INDEX.md), then targeted knowledge sections, targeted source excerpts, and authoritative web research for missing, stale, or ambiguous information. Never load the whole archive or reread unchanged material.

Respect the requested language and actual target platforms; choose other implementation details autonomously. Run analysis, tests, builds, runtime checks, and rendered visual QA appropriate to the chosen stack. Diagnose before retrying and stop redundant investigation once evidence is sufficient. Document limitations instead of claiming unperformed validation.

Keep reusable summaries in `docs/knowledge/` and source provenance in `docs/sources/`. Extend canonical documents, update the index, and commit durable changes. Project-specific decisions stay in their project.
