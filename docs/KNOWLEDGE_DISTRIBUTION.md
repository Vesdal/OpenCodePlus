# Knowledge bundle

This distribution includes locally curated guidance and indexes from Vesdal's
application-development template. It does not include the large `docs/sources/`
research archive, proprietary platform documents, copied external repositories,
or personal OpenCode configuration. Source IDs in older indexes refer to that
private evidence archive; use the named official URLs for fresh verification.

Historical status labels are not evidence that every API or license is current.
The assistant must verify version-sensitive statements before implementation.
Start with `docs/knowledge/KNOWLEDGE_INDEX.md`; retrieve only relevant sections.

The root `AGENTS.md` is portable guidance for this workspace. It does not install
system-wide rules or configure providers automatically. For generated projects,
copy the relevant guidance intentionally; never overwrite an existing project's
instructions without checking them first.
