# Derived Knowledge Base

This directory contains compact, reusable knowledge distilled from official sources, standards, repositories, and verified web research.

## Retrieval contract

1. Read `KNOWLEDGE_INDEX.md`.
2. Select documents by topic, platform, status, and retrieval hints.
3. Read only the relevant section or narrow excerpt.
4. Consult `docs/sources/` only when the derived document is insufficient or needs verification.
5. Use web research only when local knowledge is missing, stale, or ambiguous.
6. Record durable findings, provenance, and verification dates before reuse.

Knowledge documents should be small, single-purpose, deduplicated, and written as operational guidance. Large originals belong in `docs/sources/`, not here.

## Organization

- `design/` is reserved for design theory and visual-system principles.
- Future domain directories should use stable, topic-focused names.
- Existing curated documents in `docs/` remain authoritative during incremental migration; the index records their actual paths and prevents duplicate copies.
