# Android and Material 3

Material 3 is an adaptable system of tokens, components, typography, color, shape, motion, and accessibility guidance. Use semantic roles instead of arbitrary colors; support light/dark themes, dynamic color where appropriate, text scaling, and contrast.

Adaptive design changes structure and components for context, not merely size. Use panes, rails, bars, breakpoints, reflow/show-hide strategies, safe regions, foldables, multi-window, orientation, and input method intentionally.

Use touch-sized targets, clear states, semantic labels, predictable back behavior, and platform navigation patterns. Keep shapes and motion coherent with the product's hierarchy; do not apply expressive shapes or animation to every element.

Prefer window-aware layouts over device-name branching. Responsive layouts should resize content within constraints; adaptive layouts may change pane count, navigation, or information hierarchy at breakpoints. Account for multi-window, fold/hinge areas, insets/cutouts, orientation, keyboard, text scale, and large screens. Test narrow phone, landscape, tablet, desktop-sized window, and foldable configurations.
