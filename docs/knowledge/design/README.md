# Design Theory Knowledge

Reserved area for compact design-system guidance. Future documents should cover color theory and harmony, palette construction, semantic color, contrast and accessibility, typography and hierarchy, font pairing, spacing and grids, alignment and rhythm, proportion and density, information hierarchy, shape language, corner-radius geometry, borders, dividers, elevation, materials, translucency, blur, depth, iconography, motion, timing, interaction states, affordances, consistency, responsive adaptation, platform adaptation, and avoidance of generic AI-generated UI patterns.

Design guidance must express relationships rather than isolated values. In particular, document consistent radius hierarchies, smaller inner radii where nested geometry requires them, spacing scales, intentional contrast hierarchy, semantic color roles, coherent typography, controlled density, and consistent component variants.
