# Design Theory and Visual Systems

## Foundational relationships

- Use Gestalt proximity, similarity, continuity, closure, figure/ground, and common region to communicate grouping and structure.
- Establish hierarchy through content importance, scale, weight, contrast, position, spacing, and interaction priority. Alignment and shared edges create order; grids are tools, not decoration.
- Balance visual weight, rhythm, repetition, proportion, and whitespace. Density should match task frequency and context; empty space must improve comprehension or interaction.
- Typography needs a small role-based scale, consistent family/weight/line-height choices, readable line length, and deliberate pairing. Do not use giant headings as a substitute for information architecture.
- Build palettes from neutral surfaces, semantic roles, and a restrained accent. Hue, value, and saturation must serve hierarchy and meaning; never use warning/danger as decoration.
- Define a shape language and radius scale. For nested surfaces, inner radii should generally be smaller than the enclosing radius relative to inset; borders, dividers, shadows, and elevation must reinforce the same geometry.
- Use translucency, blur, gradients, and shadow only when they communicate layer, focus, or depth. Materials must preserve contrast and performance.
- Motion should explain state, causality, spatial continuity, and feedback. Use short, interruptible transitions, appropriate easing, and reduced-motion alternatives.

## Anti-pattern guardrails

Reject arbitrary purple/blue palettes, unrelated styles, excessive cards/pills/rounded containers, random sidebars, decorative gradients/glass/shadows, inconsistent spacing/radii/type, giant headings, unexplained whitespace, unjustified card grids, dashboard layouts for non-dashboard products, decorative UI without function, and platform conventions ignored for visual novelty.

## Responsive and platform adaptation

Adapt hierarchy, panes, navigation, controls, density, input affordances, safe areas, menus, dialogs, window behavior, and materials to platform and available space. Do not merely scale a desktop layout down or stretch a mobile layout up.

## Review checklist

Can a user identify the primary task, current location, next action, status, and recovery path? Are visual relationships consistent across screens? Does every decorative effect improve hierarchy, feedback, or platform fit? If not, remove it.
