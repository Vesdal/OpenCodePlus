# Knowledge Acquisition and Retrieval

1. Search `docs/knowledge/KNOWLEDGE_INDEX.md`.
2. Read only the matching derived document and relevant section.
3. Search the matching source archive path and metadata.
4. If insufficient, search official documentation, primary standards, and official repositories.
5. Retrieve only relevant sections; cross-check important claims.
6. Record URL, version/release, commit/tag, license, retrieval date, and verification date without inventing unknown values.
7. Distill reusable rules into one canonical document; do not copy whole pages.
8. Update the index, source metadata, and cross-references.
9. Validate links, duplicate concepts, language, and narrow retrieval paths.
10. Commit the durable improvement.

The source archive is evidence storage, not model context. Avoid broad crawling, repeated explanations, duplicate documents, and unpinned API claims. Mark unavailable or unverified sources explicitly.
